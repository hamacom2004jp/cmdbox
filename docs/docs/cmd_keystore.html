Command Reference ( keystore mode )

List of keystore mode commands.

keystore ( add ) : cmdbox -m keystore -c add <Option>

  • Add a key information to keystore.

Option

Type

Multi

Required

Default

Choices

Description

--host <host>

str

required

localhost

Specify the service host of the Redis server.

--port <port>

int

required

6379

Specify the service port of the Redis server.

--password <password>

passwd

required

password

Specify the access password of the Redis server (optional). If omitted, password is used.

--svname <svname>

str

required

cmdbox

Specify the service name of the inference server. If omitted, server is used.

--data <data>

dir

C:Usershama.cmdbox

When omitted, $HOME/.cmdbox is used.

--retry_count <retry_count>

int

3

Specifies the number of reconnections to the Redis server. If less than 0 is specified, reconnection is forever.

--retry_interval <retry_interval>

int

5

Specifies the number of seconds before reconnecting to the Redis server.

--timeout <timeout>

int

60

Specify the maximum waiting time until the server responds.

--key_id <key_id>

str

Unique key identifier across all keys. If omitted, it will be auto-generated.

--key_name <key_name>

str

required

Readable key name.

--key_provider <key_provider>

str

Key provider, usually a domain name. If omitted, cmdbox is used.

--key_type <key_type>

str

required

apikey

apikey | signkey | enckey | cacert

Specify the type of key information to register.

--key_usage <key_usage>

str

multi

Target commands (get_svcmd values) that can use this key. Multiple values allowed.

--key_value <key_value>

text

Actual key value. If omitted, a JWT token will be auto-generated for the current user.

--sign_key <sign_key>

file

Private key file for the public key certificate.

--sign_cert <sign_cert>

file

Public key certificate file.

--key_pass <key_pass>

passwd

Password for the private key.

--enc_key <enc_key>

str

Base64-encoded encryption key content.

--ca_cert <ca_cert>

file

CA certificate file.

--key_period_start <key_period_start>

datetime

Datetime when the key becomes valid. If omitted, effective immediately.

--key_period_end <key_period_end>

datetime

Datetime when the key expires. If omitted, no expiration.

--groups <groups>

str

multi

Groups that can use this key. Multiple values allowed.

--owner <owner>

str

multi

Owner user names of this key. Multiple values allowed.

--claims <claims>

dict

multi

Claim requirements for this key.

--signin_file <signin_file>

file

required

.cmdbox/user_list.yml

Specify a file containing users and passwords with which they can signin.Typically, specify '.cmdbox/user_list.yml'.
