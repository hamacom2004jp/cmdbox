class cmdbox.app.commons.limiter.Limiter(redis_client: RedisClient | None = None, flush_interval: float = 60.0, reload_interval: float = 60.0)[source]

Bases: object

コマンド実行に対する量的制限をチェックするクラス。

cmdbox_limiter_save で保存した制限設定をロードし、 コマンド実行前の制限チェックおよび実行後のカウンタ更新を行います。

制限設定は data_dir/.limiter/limiter-{name}.json に保存されており、 カウンタは data_dir/.limiter/counter-{name}.json に保存されます。

CHECK_ALLOW = 0
CHECK_DENY = 1
CHECK_NOT_APPLICABLE = 2
CONFIG_PREFIX = 'limiter-'
COUNTER_PREFIX = 'counter-'
COUNTER_VALKEYS = ['total_count', 'total_time', 'total_input', 'total_process', 'total_output', 'total_credits', 'total_registrations']
LIMITER_DIR = '.limiter'
REDIS_CONFIG_HASH = 'limiter:config'
REDIS_COUNTER_HASH = 'limiter:counter'
check(*, feat: LimitedFeature, data_dir: Path, logger: Logger, command_options: Dict[str, Any], current_registrations: int, scope: str = 'server') → Tuple[int, str | None][source]

コマンド実行が量的制限に違反していないかをチェックします。

マッチするすべての制限設定に対してチェックを行い、 複数の設定がマッチした場合は、すべての設定に違反している場合のみ (非0, メッセージ) を返します。 1 つ以上の設定がパスした場合は (0, None) を返します。 すべての制限をパスした場合は (0, None) を返します。

登録最大数のチェックには get_current_registrations() を呼び出します。

Parameters:

  • feat (LimitedFeature) -- 制限対象の機能

  • data_dir (Path) -- データディレクトリ

  • logger (logging.Logger) -- ロガー

  • command_options (Dict[str, Any]) -- 実行コマンドのオプション

  • current_registrations (int) -- 現在の登録数

  • scope (str) -- 対象とする制限設定のスコープ。'server' または 'client' のみ有効。

Returns:

許可する場合は Limiter.CHECK_ALLOW、制限違反の場合は Limiter.CHECK_DENY 、制限が適用されない場合は Limiter.CHECK_NOT_APPLICABLE を返します。 2 番目の要素は、制限違反の場合に表示するメッセージです。 3 番目の要素は、制限違反した制限設定の limiter_name のリストです。

Return type:

Tuple[int, Optional[str], List[str]]

Raises:

ValueError -- scope が 'server' でも 'client' でもない場合。
